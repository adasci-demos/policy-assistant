# S-03 Returns window

Customers can return a shipment through Harbourline Freight within a fixed returns window. For domestic shipments the returns window is 30 days from delivery. For international shipments the returns window is 45 days from delivery, because return transport and customs take longer.

To start a return, the customer opens a return request in the customer portal or calls the service desk with the tracking number. Staff then issue a return label. The item must be packed securely, ideally in the original packaging, and handed to a Harbourline driver or dropped at a depot before the returns window ends. A return is on time if the item is scanned at a depot or by a driver on or before the last day of the window.

Returns requested after the window has closed are refused, unless a team lead approves an exception in writing. Items that were used, altered or assembled by the customer can be returned only if the item is also damaged in transit, which is handled under the damaged items rules.

Hazardous goods follow their own rules and cannot be returned through the normal returns process. The return shipping cost is paid by the customer unless the item arrived damaged or the wrong item was delivered.
